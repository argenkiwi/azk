azk briefly had setup/clear verbs to gitignore .azk/, install reindex git hooks and build the index. They cost about 1k lines (two walks, eight nodes, hook-splicing utils) plus an --allow-run=git permission on every install, all for something done once per project. A coding agent can do the same from a short README section, and the fiddly parts (insert after the shebang, || true, the post-checkout $3 guard, git rev-parse --git-path hooks) fit in one paragraph. The Zettelkasten RAG Protocol block in the README still carries a one-line "gitignore .azk/" reminder, because it is copied into agents global instructions and agents in other projects never see the azk README. Before adding a verb, ask whether it runs often enough to be worth being code.
