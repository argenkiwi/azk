Nodes are structs like ExistsCheck<U> built with with_utils(u), and each walk struct is generic as GetWalk<U = System>. Capability traits are plain (synchronous) methods called from async fn run, so there is no boxing and no per-call Arc clone. Gotchas: default type params are not applied in expression position, so the production constructor lives in an impl on the defaulted type (impl GetWalk { fn new() -> Self { Self::with_utils(System) } }); the Node future is Send only if U: Sync and S: Send, so impls bound U: <capabilities> + Sync; and native async-fn-in-trait is not dyn-compatible, so nodes and walks cannot be trait objects. Tests pass &Fake, implementing every capability for &Fake so the test keeps ownership of the recorder. The template's per-node Utils/SystemUtils pattern this note originally described was dropped with the counter reference walk.
