azk collapsed seven per-verb walks into one graph, then split them back. The collapse was sound on its own terms — a shared factory registered under several node ids (CREATE_EMBED, UPDATE_EMBED, SEARCH_EMBED, REINDEX_EMBED) costs nothing, since NodeFactory is generic over N and ambler memoises per id. What it cost was the state: NodeFactory requires S extends NS, so one walk means one State that is a structural supertype of every node's, which forces every per-verb field optional and makes a union of per-verb result types uncompilable. Splitting restores required fields (args, verb) and drops the verb prefixes from node ids, because a position is only ambiguous when several verbs share a graph. The reuse that mattered survives the split untouched: the unit of reuse is the node file and its tests, not the graph position, so embed is still written once and wired into four walks. Note the type system barely polices a split walk's State — every node State is an all-optional weak type, so omitting *some* of a node's fields compiles silently and still works at runtime (nodes spread {...state} through), and only omitting *all* of them errors.
