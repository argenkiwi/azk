NodeFactory requires S extends NS, so the walk's State must be a structural supertype of every node's. Two consequences bite when seven subcommands collapse into one walk. First, a node can no longer declare a field required: {id?: string} does not extend {id: string}, so every per-verb field becomes optional and nodes read them as state.id! with a comment naming the guard node upstream. Only argv stays required, because it is the one field every verb sets before any node reads it. Second, a shared result field is impossible: {result?: A|B} does not extend {result?: A}, so a union of per-verb result types fails to compile. Rather than seven *Result fields, terminal nodes now just print and their tests assert on the captured print output — which is the CLI's actual contract anyway. These errors surface as parameter contravariance against the walk's wiring line, never against the node that caused them.
