utils::embed POSTs {model, prompt} to {EMBEDDING_HOST}/api/embeddings (Ollama native API, not the OpenAI-compatible /v1 the Deno build used), defaulting to localhost:11434 and nomic-embed-text; a host without a scheme gets http:// prepended. There is no dotenv dependency, so a .env file is ignored, unlike the Deno build installed with --env-file. Semantic search skips stored vectors whose dimension differs from the query, so mixing models degrades silently rather than erroring, and reindex only re-embeds notes whose body hash changed, so changing EMBEDDING_MODEL needs rm -rf .azk && azk reindex. A Deno-built .azk/ must be deleted outright: its links table has a NOT NULL created column and no primary key, which breaks the Rust INSERT OR IGNORE link writes.
