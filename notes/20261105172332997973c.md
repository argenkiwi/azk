The Deno/TypeScript implementation was replaced wholesale by the Rust port from the azk branch of argenkiwi/ambler-rs, imported as files rather than merged history. The template leftovers were dropped: the counter reference walk, its count/start/stop nodes, utils::terminal, and the `ambler` package name (the crate is now `azk`, lib and bin). rand stays because utils::clock uses it for note ids; tokio no longer needs its time feature. The .agents skills were rewritten around the azk conventions (capability traits plus System, impl_has!, testing::Fake, walks generic over U = System) because the template versions taught a per-node SystemUtils pattern azk no longer uses. Syncing from ambler-rs again therefore means re-applying these trims, not a straight copy.
