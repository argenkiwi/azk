`azk help [verb]` is the one verb that breaks the single-JSON-value-on-stdout rule: its output is documentation meant for an agent to read, and escaping Markdown into a JSON string only gets in the way. The guides are src/guides/<verb>.md, pulled in with include_str! by src/nodes/help.rs, so they read as Markdown in the repo yet an installed binary never needs its source directory at runtime. (The Deno build kept them as TS string constants for the same reason.) This makes the CLI the sole source of truth for output shapes and gotchas. Tests in src/walks/help.rs assert every verb has a guide starting `# azk <verb>`, which catches a verb added without docs.
