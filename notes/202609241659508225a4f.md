`azk help [verb]` is the one verb that breaks the single-JSON-value-on-stdout rule: its output is documentation meant for an agent to read, and escaping Markdown into a JSON string only gets in the way. The guides live as string constants in utils/help.ts rather than .md files read at runtime, because a `deno install`ed binary should not need read permission on its own source directory and Deno text imports are still unstable. This makes the CLI the source of truth for output shapes and gotchas; the azk-reference skill is now just a pointer to `azk help`, so new verb behaviour belongs in utils/help.ts, not the skill. Tests assert every guide shows `azk <verb>` and that the general guide lists every verb, which catches a verb added without docs.
