Each walk is a library module in src/walks/<name>.rs whose public surface is only `pub type Error` (or enum) and `pub async fn run(args)`; State, Id and the node-owning struct stay private. Its wiring test is a #[cfg(test)] module in the same file, driven by with_utils(&fake), where testing::Fake implements every capability trait for &Fake, so walks and nodes follow one testing convention. A tests/ integration test was rejected because it forced pub fields and test-only constructors onto the walk, and an earlier draft ended up with the same test duplicated in both places. src/main.rs names only walks::<verb>::Error, never a node's error, so every dispatch arm is the same. Default type params are not applied in expression position, so each walk keeps a private `impl GetWalk { fn new() }` on the defaulted type for production wiring.
