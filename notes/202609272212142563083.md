The sample Zettelkasten RAG Protocol in the README is pasted into agents global instruction files, so it costs context in every session. It is kept to the behavioural protocol (when to search, get only 1-3 hits, what makes a note worth creating, update over contradicting, when to reindex) and tells the agent to run azk help / azk help <verb> before first using a verb. Command syntax, JSON output shapes, the {error}-with-exit-0 convention and embeddings config live only in utils/help.ts; do not copy them back into the protocol, or the two will drift.
