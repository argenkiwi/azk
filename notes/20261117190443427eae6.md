amble check requires each node file to hold one struct named after the file, so the old grouped files (nodes/create.rs with Input/Init/Finish, etc.) were split into verb-prefixed files: create_input, help_print, link_validate, reindex_list, search_keyword, update_merge and so on. Each file's outcome enum is just `Outcome`, referenced from walks as `create_input::Outcome`; walk Id variants (and so the specs' ### headings) kept their short names. State traits that only one walk needs (HasTopic, HasLinkArgs, HasQueue, HasSearch) moved into nodes/mod.rs with impl_has! arms (topic, link_args, queue, search), so node tests and walks share one implementation; the guides table and by_position ranking helper also live there because two nodes each need them. testing::Fake gained fail_index_reads and fail_notes (fail_index now covers every index write) so node tests can reach error branches; fail_index deliberately does not break indexed_hash, or reindex walk tests would fail in DetectChange instead of IndexUpsert.
